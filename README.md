# 📚 Materi Pembelajaran

## 📌 Casting Tipe Data Umum

Materi dasar mengenai konversi tipe data bawaan Python.

### Daftar Materi

- ✅ Casting Tipe Data Umum Integer (`int`)
- ✅ Casting Tipe Data Umum Float (`float`)
- ✅ Casting Tipe Data Umum String (`str`) menggunakan tanda kutip tunggal (`'...'`)
- ✅ Casting Tipe Data Umum String (`str`) menggunakan tanda kutip ganda (`"..."`)
- ✅ Casting Tipe Data Umum Boolean (`bool`) bernilai `True`
- ✅ Casting Tipe Data Umum Boolean (`bool`) bernilai `False`

---

## 📌 Casting Tipe Data Khusus

Materi mengenai konversi berdasarkan nilai dari berbagai tipe data.

### Daftar Materi

- ✅ Casting menggunakan nilai Integer (`int`)
- ✅ Casting menggunakan nilai Float (`float`)
- ✅ Casting menggunakan nilai String (`str`) dengan tanda kutip tunggal (`'...'`)
- ✅ Casting menggunakan nilai String (`str`) dengan tanda kutip ganda (`"..."`)
- ✅ Casting menggunakan nilai Boolean (`bool`) bernilai `True`
- ✅ Casting menggunakan nilai Boolean (`bool`) bernilai `False`
- ✅ Casting menggunakan seluruh tipe data umum
